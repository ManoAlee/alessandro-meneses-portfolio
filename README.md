## 🚀 Sobre este Repositório

Este repositório contém o código-fonte do portfólio pessoal e corporativo de Alessandro Meneses. Foi projetado e desenvolvido sob os mais altos padrões de design gráfico para a web e engenharia de software frontend:

* **Arquitetura Double-Bezel (Doppelrand):** Envoltórios aninhados simulando hardware de precisão em todas as seções e cartões.
* **Paleta Obsidian Zinc:** Modo escuro de alto contraste em `#09090b` combinado a um modo claro minimalista com alternância fluida.
* **Microinterações Hápticas:** Efeitos de inclinação 3D reativos ao mouse com física de molas via Framer Motion.
* **Padrão Button-in-Button:** Botões com setas direcionais em pílulas aninhadas cinéticas (`↗`).
* **Feature-Sliced Design (FSD):** Arquitetura modular e desacoplada em camadas previsíveis.

## 🧭 Estrutura e Funcionalidades das Páginas

### 1. Início (`/`)
* **Hero Cockpit com Code Inspector:** Painel interativo com 3 abas reais (`perfil.ts`, `automacao.py`, `stack.json`) exibindo código real com destaque de sintaxe.
* **Bento Grid de 4 Pilares:**
  1. *Desenvolvimento de Software* (React, TypeScript, Tailwind, APIs)
  2. *Automação de Processos & Scripts* (Python, PowerShell, Bash)
  3. *Sustentação de Sistemas de TI* (Active Directory, Windows Server, Linux, TCP/IP)
  4. *Dashboards & Análise de Dados* (Power BI, DAX, SQL, ETL)
* **Vitrine de Repositórios:** Cards com badges de linguagem em tempo real e links diretos para o GitHub.

### 2. Projetos & Repositórios (`/opensource`)
* **Modo Gráfico:** Cards com física de rotação 3D calculada pelo movimento do mouse (`preserve-3d`), badges de visibilidade e filtros instantâneos.
* **Modo Terminal CLI:** Emulador interativo de linha de comando com histórico, digitação em tempo real e botões de atalho rápido em 1 clique (`help`, `about`, `skills`, `projects`, `status`, `clear`).

### 3. Especialidades Técnicas (`/expertise`)
* **Canvas de Grafos Dinâmicos:** Renderização de malha interativa em HTML5 Canvas com conexões elásticas e ondas de choque ao clique.
* **Matriz de Competências:** Filtro por categorias (*Essenciais, Linguagens, Ferramentas*).
* **Trajetória Profissional:** Linha do tempo estruturada com histórico na Automotion e na BR Conecta, além da graduação na FATEC.

### 4. Serviços & Soluções (`/services`)
* **Catálogo de Soluções:** Especificações técnicas detalhadas em formato de módulos.
* **Metodologia de Entrega:** Fluxo em 4 fases (*Diagnóstico & Escopo ➔ Arquitetura & Prototipação ➔ Desenvolvimento & Testes ➔ Homologação & Entrega*).
* **FAQ Interativo:** Acordeão dinâmico respondendo dúvidas sobre prazos e escopo.

### 5. Currículo Executivo (`/resume`)
* **Layout Suíço / Editorial:** Formatação de alto nível tipográfico com resumo profissional e conquistas quantificáveis.
* **Impressão Inteligente (`@media print`):** Regras de CSS dedicadas para gerar PDFs executivos limpos e sem elementos de navegação através do botão *Imprimir / Salvar PDF*.

### 6. Contato (`/contact`)
* **WhatsApp Direto:** Botão de 1 clique com mensagem pré-preenchida para agilidade.
* **E-mail com Cópia Rápida:** Botão de cópia para a área de transferência com notificação via *toast*.
* **Garantia de Resposta:** Badge informando compromisso de retorno em menos de 24 horas úteis.

## 💻 Como Rodar o Projeto Localmente

### Pré-requisitos
* **Node.js** versão 18.0 ou superior
* **npm** ou **yarn** instalado

### Instalação e Execução

1. **Clonar o Repositório:**
   ```bash
   git clone https://github.com/ManoAlee/alessandro-meneses-portfolio.git
   cd alessandro-meneses-portfolio
   ```

2. **Instalar Dependências:**
   ```bash
   npm install
   ```

3. **Iniciar Servidor Local de Desenvolvimento:**
   ```bash
   npm run dev
   ```
   *O projeto será executado em:* `http://localhost:5173`

4. **Verificação de Tipos (TypeScript):**
   ```bash
   npm run typecheck
   ```

5. **Gerar Build Otimizado de Produção:**
   ```bash
   npm run build
   ```
